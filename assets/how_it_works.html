How it works

貼って、待つだけ。AIがコードを監査して、安全に直すまで。

1
貼る
監査したいプロジェクトで、合言葉かプロンプトを1回投げるだけ。毎回プロンプトを書く必要はありません。
your-project
# プロジェクト直下で
> run audit --ultracode
→
2
走る
AIが最適なプロンプトを自動で選択。ultracode なら複数エージェントが並列で観点ごとに監査します。
auditing...
security
vuln
bug
maintain
→
3
こうなる
指摘が観点ごとに整理され、現行機能を壊さない範囲で修正まで。ビルドもコミットも勝手にやりません。
report
⚠SQLi: users.go:42
⚠XSS: render.ts:18
✓安全に修正 / 要判断は記録
📝毎回プロンプトを書かない型を1度作れば貼るだけ
🎯指示がブレない不変条件を正本で固定
⚡止まらず最後まで走る要判断は記録してパス
